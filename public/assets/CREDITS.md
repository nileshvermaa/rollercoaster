# Art credits

All painted art in this folder was generated for this project from the design spec
(`docs/GAME_DESIGN.md`) with an image generator, then cut out with `tools/cutout.py` /
`tools/slice_sheet.py` in the design workspace.

These are **first-draft placeholders**: most were sliced from composite reference sheets, so
they are low resolution. Replace each file with a full-size individual export of the same name
(see `docs/ART_PIPELINE.md`); no code changes are needed.
